# Cloud Flow Ready-to-Use Solution

> [!WARNING]
> **Do not import or deploy this solution before the workshop.**
> This is a catch-up resource for use **during or after Module 3**, not a pre-workshop prerequisite.

## Purpose

This folder is reserved for a ready-to-use solution to help participants catch up on the cloud flows covered in [Module 3: Create supplier-delay intake and live impact with Power Automate](../../labs/03-build-intake-and-impact-cloud-flows.md):

- **Order Disruption Cloud Flow**
- **Supplier Disruption Impact Assessment Cloud Flow**

Follow the Module 3 lab to build the flows yourself whenever possible. Use the ready-to-use solution if you fall behind during the module or want to complete the cloud flow exercises afterward.

## Before using the solution

- Confirm with your facilitator that you should use the catch-up solution.
- Complete the Module 3 prerequisites and use your assigned workshop environment.
- Review any flows you have already created with your facilitator to avoid running duplicate flows.
- After import, configure the required connections and follow the Module 3 testing steps.

## Package availability

No solution package is included in this folder yet. A solution ZIP must be added before this catch-up resource can be imported.
